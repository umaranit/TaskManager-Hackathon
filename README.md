
Hackathon Content: Modernizing the Task Manager Application
Hackathon Title:
"Modernize and Innovate: Task Manager 2.0"
________________________________________
Objective:
Participants will modernize the provided Task Manager application by implementing a modern front-end framework, integrating a back-end API with microservices architecture. The goal is to create a innovative, scalable, feature-rich, and intelligent task management solution.
________________________________________
Hackathon Deliverables:
Participants are expected to deliver the following:
1.	Modernized Front-End:
o	Replace the existing jQuery-based front-end with a modern framework such as React.js, Angular, or Vue.js. (Choose one of the technologies).
o	Ensure the UI is responsive and adheres to modern design principles.
o	Maintain and enhance the existing functionality (e.g., task addition, editing, deletion, sorting, and searching).
2.	Back-End API with Microservices Architecture:
o	Develop a back-end API using Java, .NET, or Python. (Choose one of the technologies).
o	Implement a microservices architecture to handle different functionalities (e.g., task management, user authentication, analytics).
o	Ensure the API is RESTful and follows best practices for scalability and maintainability.
o	If possible, use Json or in-memory database.
3.	Documentation:
o	Provide clear documentation for the front-end, back-end, and database setup.
o	Include instructions for deploying the application locally or on the cloud.
________________________________________
Hackathon Guidelines:
1.	Team Composition:
o	Teams can consist of 4 members.
o	Each team should have a mix of front-end, back-end, and database expertise.
2.	Technology Stack:
o	Front-End: React.js or Angular, or Vue.js.
o	Back-End: Java (Spring Boot), .NET (ASP.NET Core), or Python (Flask/Django/FastAPI).

3.	Evaluation Criteria:
o	Functionality: How well the application works and meets the requirements.
o	Code Quality: Clean, modular, and well-documented code.
o	Scalability: Use of microservices.
o	UI/UX: Modern and user-friendly interface.
4.	Submission Requirements:
o	Source code hosted on GitHub or any other version control platform or on local system.
________________________________________
Hackathon Timeline: 6- 8 hours

To evaluate the teams, consider:
•	Creativity & Completeness: How well did the team understand and implement the use case?
•	Utilization of GitHub Copilot: Did they effectively use Copilot to assist with coding and problem-solving?
•	Code Quality, Unit Tests & Documentation: Is the modernized implementation clean, efficient, and well-documented?
•	Demo: A working output

Guidance for Participants
1.	Focus on Core Requirements:
o	Ensure that all mandatory features (modernized front-end, back-end API, database integration, and AI feature) are implemented and functional.
2.	Plan Your Architecture:
o	Use a modular approach for both front-end and back-end development.
3.	Leverage Modern Tools and Libraries:
o	Use popular frameworks like React.js, Angular, Vue.js, flutter etc for the front-end.
o	For the back end, choose a robust framework like Spring Boot (Java), ASP.NET Core (.NET), or Flask/Django/FastAPI (Python).

4.	Test Thoroughly:
o	Test the application for bugs, edge cases, and performance issues.
o	Ensure cross-browser compatibility for the front-end.
5.	Document Everything:
o	Provide clear instructions for setting up and running the application.
o	Include a README file with details about the architecture, features, and any third-party tools used.
